# Portfolio Content Governance

The Obsidian Experience Library is the authority for career facts. This repository contains only the public presentation derived from that evidence.

## Publishing rules

1. Check every role, date, technology, metric, status, and contribution against the matching Experience Library note.
2. Classify each claim as verified, user-confirmed, inferred, or withheld.
3. Publish verified and user-confirmed claims only. Inferences may guide drafting but must not appear as facts.
4. Keep client names anonymized until public naming permission is documented.
5. Recheck dynamic product metrics immediately before use; omit them when a fresh source is unavailable.
6. Record the review date on every indexable work page.
